# Suivi d'appels Rouage — BD2

Chaque prospect est une **Issue** de ce dépôt : https://github.com/dossyne-labs/rouageb2b/issues

## Mettre à jour un statut
1. Ouvre l'Issue de l'entreprise (depuis la page du tableau de bord, ou directement dans l'onglet **Issues**).
2. À droite, dans **Labels**, retire l'ancien `statut: …` et coche le nouveau.
3. Laisse un commentaire si besoin (date de relance, ce qui a été dit) — tout l'historique reste visible dans l'Issue.

## Tableau de bord
La page en ligne (GitHub Pages) lit automatiquement les Issues et affiche la liste, les priorités et les statuts — pas de compte ni de connexion nécessaire pour la consulter.

## Labels
- `statut: …` — l'état de l'appel (à-appeler, tenté, barrage, messagerie, injoignable, décideur joint, refus, RDV obtenu, sans suite)
- `priorite: A / B / C` — la priorité d'appel
- `a-requalifier` — une info du dossier est à revérifier avant l'appel
- `sans-numero` — aucun numéro de téléphone trouvé pour l'instant
